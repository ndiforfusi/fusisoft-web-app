FAQ

Why use relative links?

Relative links (like ./assets/app.js) work whether the site is served at / or under /devops-demo/.

Can I add API calls later?

Yes. Add endpoints in Nginx (reverse proxy) and update the JS to call them.

Is Tailwind CDN production-ready?

CDN is fine for demos. For production, compile Tailwind in a build step and serve static CSS.
